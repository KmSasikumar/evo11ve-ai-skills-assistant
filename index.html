How it works

    
    
      
  1. Question — typed, spoken (browser speech recognition), or picked from a suggestion.
    2. 
      
  2. Match — the question is scored against a knowledge base built only from evo11ve.ai/for-ai (fetched 29 Oct 2026).
    3. 
      
  3. Answer or escalate — a matching program fact is answered (and spoken aloud if voice replies are on). No match, or a fact the page does not state, produces an honest “not stated” answer with a callback / human-escalation email draft.
    4. 
      
  4. Email triggers — enrollment, callback, and human-escalation intents compose the exact email and hand it to your own mail app. Nothing is reported as sent, because a web page cannot confirm delivery; server-side sending can be wired at the documented point in app.js.
    5.
